# Pi-Agent Mobile OS App

Flutter client for the Pi-Agent Mobile OS gateway. It provides encrypted computer binding, separate phone and remote-computer file browsers, GitHub search and clone, project summaries, server-driven capabilities, detailed analysis, natural-language tasks, durable conversation history, live progress, cancellation, structured results, and a code-change graph.

## Bootstrap platform files

Flutter platform scaffolding is intentionally generated by the installed Flutter SDK so it matches that SDK version:

```bash
flutter create --platforms android,ios .
flutter pub get
```

## Run

Android emulator:

```bash
flutter run --dart-define=GATEWAY_URL=http://10.0.2.2:8787 --dart-define=GATEWAY_TOKEN=change-me
```

For a physical phone on the same LAN, replace `10.0.2.2` with the gateway machine's LAN address. The gateway must listen on that address and must have `PI_MOBILE_TOKEN` configured.

For private access over the internet, keep the Gateway bound to loopback and expose it only inside the user's own Tailscale network. See [Self-hosting with Tailscale](../SELF_HOSTING_TAILSCALE.md).

The startup values are defaults only. Open **绑定电脑** in the app to verify another Gateway address and save its token in Android encrypted storage. The **手机文件** tab delegates access to Android's system picker; the **电脑文件** tab can only browse `PI_MOBILE_PROJECT_ROOTS`.
